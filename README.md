# 📝 Android Notes App  

A simple and user-friendly **Notes Application** built for Android.  
This app allows users to **add, edit, search, and delete notes** easily, helping them organize their ideas and tasks effectively.  

---

## ✨ Features  

- ➕ **Add Notes** – Create and save new notes instantly.  
- ✏️ **Edit Notes** – Update your existing notes anytime.  
- 🔍 **Search Notes** – Quickly find notes using keywords.  
- 🗑️ **Delete Notes** – Remove notes you no longer need.  
- 📱 **Clean & Simple UI** – Easy-to-use interface for a smooth experience.  

---

## 🛠️ Tech Stack  

- **Language**: Kotlin  
- **Architecture**: MVVM 
- **Database**: Room Database
- **UI**: Material Design Components
